# ESP32-S3 RLCD 4.2 天気時計

天気サービスを選べます。初期設定はQWeatherで、Open-Meteoを有効にするとQWeatherのKey/Hostは不要です。大気質はUS AQI、気象警報は非対応で、自動的に別サービスへ切り替えません。公開APIは非商用向けです。データ：[Open-Meteo](https://open-meteo.com/) / [CAMS](https://atmosphere.copernicus.eu/)、都市検索：[GeoNames](https://www.geonames.org/)。

[简体中文](README.md) · [繁體中文](README_zh_TW.md) · [English](README_EN.md) · 日本語（現在）

WaveshareのESP32-S3と4.2インチRLCDを使った卓上時計です。常時読める画面に、天気、温湿度、画像、カレンダー、通知、Xiaozhi AIをまとめています。必要なときだけ通信や音声を動かす設計を重視しています。

本体UIは主に簡体字中国語です。日本語ドキュメントは本体の言語切り替えを意味しません。初回は本体のアクセスポイントに接続し、Wi-Fi、自分のQWeather Key、専用API Hostを設定します。予備のWi-Fiと都市は省略可能です。オフラインなら日付と時刻を設定して使えます。

## 8つの画面

1. 天気時計：大きな時刻、天気、GIF、警報、状態表示。
2. 画像時計：曜日別の内蔵画像または自作画像、分単位の時計、ひとこと。
3. 天気ダッシュボード：現在の天気、予報、大気質、風、日の出・日の入り。
4. 温湿度時計：コントラストの高い数字、温湿度、傾向、日付と旧暦。
5. カレンダー：月表示、今日、旧暦、祝日表示。
6. 温湿度履歴：過去24時間の測定グラフ。
7. Xiaozhi AI：音声対話、字幕、表情、アラーム、集中タイマー、都市設定。
8. 統合時計：大きな時計、当日の天気、日付・旧暦、温湿度を点描調に配置。

画面の有効化と順序を変更でき、先頭がホームになります。AI以外の画面を最低1つ残します。各画面は天気やセンサーのデータを共有し、非表示画面は無駄に再描画しません。内蔵画像は曜日に合わせて毎日切り替わり、アップロード画像は30分から24時間の周期を選べます。

## 操作と通信

BOOTの短押しで画面切り替え・決定、KEYの短押しで設定・項目移動、長押しで戻ります。AIでは単発アラーム1件と独立した集中タイマーを扱えます。音声の返答だけでなく、画面の設定結果も確認してください。

Wi-Fiはメインと予備の2組を保存し、接続失敗時に切り替えます。都市は設定ページ、ブラウザーツール、音声で指定でき、自動位置判定へ戻すこともできます。オフラインではネット接続が必要な画面を無効にします。サービス側の気温と本体センサーの値は別の測定です。

## 描画と省電力

UIは主にLVGLで実装しています。文字、メニュー、状態表示はウィジェット、時計や画像、グラフはCanvasなどの描画を利用し、RLCDドライバーがモノクロ転送と部分更新を担当します。

ESP-IDFの動的電源管理でCPUを負荷に応じて40–240MHzに調整し、FreeRTOS Tickless IdleとLight Sleepを活用します。Wi-Fiは省電力モードで動作し、通常の同期後は無線を停止します。音声終了後はCodecを解放します。通常運用にDeep Sleepは使いません。

秒表示は変わった数字だけ、低頻度の画面は分・日付・データの変化に合わせて更新します。センサーは昼間約1分、夜間約2分間隔です。実際の持続時間は電池、基板、AI使用状況に左右され、瞬間的な電流だけでは判断できません。

## 更新と素材

App binはアプリのみで、OTAや正しいアプリ領域への書き込みに使用します。0x0には書き込みません。Merged binはbootloader、パーティションテーブル、OTA選択、音声モデル、Appを含む全体イメージで、0x0から書き込み、データを上書きする場合があります。OTAではパーティションテーブルを更新できません。

ブラウザーツールで画像やGIFの変換、ファームウェアのハッシュ確認、シリアル書き込みができます。素材がない・検証できない場合は内蔵素材に戻ります。Webサイトだけの変更では、新しいファームウェア版を作る必要はありません。
