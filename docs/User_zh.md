# WeatherClock 简易用户手册

[详细说明](User_Detailed_zh.md) · [繁體中文](User_zh_TW.md) · [日本語](User_ja.md) · [English](User.md)

## 先完成配网

1. 开机后连接屏幕显示的 `WeatherClock-` 热点，密码以屏幕为准。
2. 打开自动弹出的网页；没有弹出就访问 `http://192.168.4.1/`。手机提示无互联网时选择保持连接。
3. 填写主 Wi-Fi、密码、自己的 QWeather API Key 和账号专属 API Host。备用 Wi-Fi 和天气城市可留空。
4. 点击保存并等待验证；失败按提示修改，成功后设备自动进入工作页。

API Host 填和风天气控制台显示的专属域名，不是 API Key，也不要填接口路径。只想离线使用时，Wi-Fi 留空，填写日期时间即可。联网使用时离线日期时间可留空。

## 两个按键

- **BOOT 短按**：切换工作页；在设置里确认。
- **KEY 短按**：进入设置；在设置里移动选择。
- **KEY 长按**：返回上一级，或退出设置。
- **提示音播放时按任意键**：先停止闹钟/番茄钟提示音。

设置里约 30 秒不操作会自动退出。

## 日常使用

八个页面分别是天气时钟、图片时钟、天气看板、温湿时钟、日历、温湿历史、小智 AI、聚合时钟。“设置 → 显示”可开关和排序，第一项是主页，至少保留一个非小智页。

天气按需整点更新。内置图片按星期每天切换；自定义图库可调整周期。本地温湿度白天约每分钟、夜间约每两分钟采样。小智耗电较高，使用时发热可能影响本地温度。

小智可以设置单次闹钟、番茄钟和天气城市。请核对屏幕结果；普通延时提醒是闹钟，“专注/番茄钟”才是专注计时。已有闹钟被替换前需要确认。

## 更新、资源与常见问题

- OTA：“设置 → 系统 → 检查更新”，按 BOOT 检查，发现更新后在 60 秒内确认。
- [WeatherClock Studio](https://wickenzh.github.io/ESP32-S3-RLCD-4.2/)：在电脑浏览器制作素材、查看预览、写入固件和读取日志。
- 网页支持窄屏浏览，模拟器会自动改为上下布局；写入素材、烧录固件和串口功能仍需支持 Web Serial 的桌面版 Chrome 或 Edge。
- 固件页默认提供“在线完整安装”，首次安装或分区迁移应先连接设备并确认芯片与 Flash 容量，再确认覆盖固件、分区表和资源。要保留设备配置或自定义资源，请取消并使用下方高级 App 更新；手机只能浏览，不能进行串口安装。
- 网页右上角可切换简体中文、繁体中文、日本语或英语，浏览器会记住选择；不改变固件画面或配网模拟器内部语言。
- 天气不更新：先检查 Key、Host、网络及服务权限；旧缓存不代表同步成功。
- Wi-Fi 图标表示射频开启，不保证已联网。电量与充电图标是估算，插着 USB 不一定一直充电。
- 离线模式下只能启用本地页面；重新联网需要完整配置。
- **App bin 不能刷到0x0；OTA不能更新分区表。** 首次刷机或旧分区迁移请阅读详细说明和发行说明。
- 恢复出厂会清除网络和普通设置，但保留小智绑定、历史及自定义资源；不等于全片擦除。

不要公开带有 Wi-Fi 密码、API Key 或私人地址的日志、截图和快捷配置链接。更多操作和故障处理见[用户详细说明](User_Detailed_zh.md)。
当前固件固定使用 UTC+8 时区，没有时区切换选项；日文/英文手册不改变设备时区。

## 可选天气源

开启后，和风 Key/Host 输入框保留显示但禁止输入，关闭开关即可恢复编辑。网络检测使用当前天气源；关于本机显示当前来源最近一次成功同步的时间，切换来源后需等待首次同步成功。

配网页和 WeatherClock Studio 快捷配置提供“使用 Open-Meteo”开关，默认关闭。关闭时使用和风天气，需要原有 Key/Host；开启后无需填写这两项，且不会删除已保存的和风凭据，也不会自动切回和风。选择和风后如无凭据仍需补填。

Open-Meteo 使用模型天气，空气质量明确显示 US AQI，不是中国 AQI；不提供本项目的天气预警，界面会提示不支持。公共接口限非商业使用，需网络可达，不保证无超时。快捷配置需要支持双天气源的新固件，旧固件可能忽略开关。离线仍只填写有效日期时间。

数据：[Open-Meteo](https://open-meteo.com/)、[CAMS](https://atmosphere.copernicus.eu/)；城市：[GeoNames](https://www.geonames.org/)。
