# WeatherClock 用户详细说明

[简易手册](User_zh.md) · [English](User_Detailed.md) · [繁體中文](User_Detailed_zh_TW.md) · [日本語](User_Detailed_ja.md)

适用于当前八页面固件。设备界面主要为简体中文；本手册的多语言版本不代表固件已提供语言切换。升级前请同时阅读对应版本的发行说明。

## 1. 第一次使用

1. 给设备供电，等待启动完成。首次使用或恢复出厂设置后，设备会进入配网模式。
2. 手机或电脑连接屏幕显示的 `WeatherClock-` 热点，密码以设备屏幕为准。
3. 等待自动打开配网页；未弹出时，在浏览器输入 `http://192.168.4.1/`。如手机提示没有互联网，选择保持连接，暂时关闭自动切换移动数据。
4. 联网使用填写主 Wi-Fi、密码、QWeather API Key 和账号专属 API Host。备用 Wi-Fi 和天气城市可以不填。
5. 保存后等待验证结果。成功后设备退出配网进入主页；失败时按网页提示修改，不必反复恢复出厂设置。

**API Host** 是和风天气控制台分配给账号的域名。复制域名本身，不要填 API 路径、API Key 或旧的公共域名。天气验证失败时，应同时检查 Host、Key、服务权限和网络。

已有 Wi-Fi 信息不代表天气服务已经配置完整。新用户必须准备自己的天气凭据，不要使用他人公开的密钥。

## 2. 按键和状态栏

| 操作 | 工作页面 | 设置页面 |
| --- | --- | --- |
| BOOT 短按 | 切到下一个已启用页面 | 确认或修改当前选项 |
| KEY 短按 | 进入设置 | 移动选择 |
| KEY 长按 | 以当前页面提示为准 | 二级返回一级，一级返回工作页 |

设置中约 30 秒无操作会退出；排序时正常按键也会重置这个计时。响铃时任意按键先停止提示音，本次按键不会再执行切页。

- 电池图标显示估算电量；闪烁是软件推断的充电状态，不是 USB 连接指示。
- Wi-Fi 图标表示射频开启，不保证已经连接互联网。
- 喇叭图标表示提醒功能开启；闹钟图标表示有已启用的单次闹钟。
- 顶部时间仅在主体没有时钟、或小智时钟区域被番茄钟占用时显示。
- 全天进度条反映一天的进度。页面按数据变化局部刷新；切页或较大内容变化仍可能整屏更新。

## 3. 八个工作页面

| 页面 | 主要内容 | 更新方式 |
| --- | --- | --- |
| 天气时钟 | 大时钟、天气、预警、GIF、本地温湿度 | 时间按秒；天气按需整点同步 |
| 图片时钟 | 图片、分钟时钟、每日文字 | 时钟按分钟；图片按配置切换 |
| 天气看板 | 当前天气、未来预报、空气质量、风力、日出日落、建议 | 天气共享缓存；日出日落倒计时按分钟 |
| 温湿时钟 | 时分秒、本地温湿度、趋势表情、日期农历 | 时间按秒；传感器按采样节奏 |
| 日历 | 当月日期、农历、节日、今日高亮 | 日期变化或重新进入时重绘 |
| 温湿历史 | 最近 24 小时温湿度曲线 | 后台记录小时样本，数据变化时更新 |
| 小智 AI | 唤醒、对话、字幕、表情、语音工具 | 按语音会话和计时状态更新 |
| 聚合时钟 | 秒级时间、当天天气、日期农历、本地温湿度 | 复用上述时间、天气和传感器数据 |

天气温度来自服务端；本地温湿度来自设备传感器，二者不应当作同一测量位置。趋势箭头表示最近四小时内有效样本的滚动平均变化，重启后重新积累。

内置图片按实际星期显示，每天零点切换。自定义图库优先于内置图库，支持 30 分钟、1、6、12、24 小时切换，以当天零点为基点。每日文字有独立缓存。

天气看板的建议参考今天的预报，晴天时仍可能因当天其他时段有雨而提示带伞。同步失败可继续显示旧缓存，不表示刚刚更新成功。

## 4. 网络、城市和离线模式

主、备 Wi-Fi 可以保存两组；备用可以留空。首选多次连接失败后会尝试另一组，连接成功的组成为新的首选。两组都不可用时按退避策略稍后重试，不应持续快速重连；需要修改凭据时进入配网。

城市留空使用自动定位，IP 定位可能偏离实际位置。可通过配网页、上位机或小智语音指定城市，例如“把天气城市设置为杭州市”。城市必须能通过天气服务查询；同名城市应加上地区信息并核对最终显示。不要输入与实际城市无关的描述。

“设置 → 网络 → 天气城市”可二次确认清除手动城市并恢复自动定位，随后尝试刷新天气。修改时若正在进行语音或其他高负载任务，刷新可能稍后执行。

离线使用时，不填 Wi-Fi，只填写有效的本地日期时间；无需 API Key 和 API Host。联网配网时，离线日期时间可以留空。

开启离线模式会停止普通联网，并使天气时钟、图片时钟、天气看板、小智 AI、聚合时钟不可启用。可使用温湿时钟、日历和温湿历史。关闭离线模式时，完整联网配置存在可直接恢复；配置不完整则需要二次确认进入配网。离线不等于删除所有缓存。

## 5. 设置菜单

- **网络**：进入配网、同步时间、同步天气、更新每日文字和查看/清除手动天气城市。天气时钟、天气看板、聚合时钟共用同步结果。
- **声音**：选择现有提示音、调节音量，开启整点或全天提醒。小智会话与提示音需要共享音频资源，冲突时按设备保护规则处理。
- **显示**：页面开关、页面顺序、小智节能、单次闹钟和图片切换周期。
- **系统**：离线模式、网络检测、恢复出厂设置、关于本机和检查更新。

页面顺序只列出已启用页；KEY 选择，BOOT 按提示交换位置。第一项为主页。至少保留一个非小智工作页，小智不能排在第一位。温湿历史与一般页面一样可关闭和排序，不再有固定五分钟返回限制。

“小智节能”默认开启：小智页五分钟无有效操作返回主页。番茄钟运行期间暂停自动返回。图片切换选项只对自定义图库可调，内置图库固定为 24 小时。

## 6. 小智、闹钟与专注计时

首次使用小智可能需要按屏幕或语音提示完成账号绑定。它需要网络，等待唤醒也比普通时钟耗电，长时间使用可能使电路板发热，影响本地温湿度读数。

可以说：
- “明天早上六点半叫我。”
- “开始一个二十五分钟番茄钟。”
- “番茄钟还剩多久？”“取消番茄钟。”
- “把天气城市设置为上海。”“天气城市改为自动。”

语音识别和工具调用可能理解错误，请核对屏幕上的时间、计时状态或城市，不能仅凭一句口头回复判断设置成功。

**闹钟**只允许一个，单次有效。覆盖已有不同时间的闹钟需要确认；设置里可以关闭。响铃最长约一分钟，中间间隔约五秒重复，按任意键停止。闹钟与番茄钟结束提醒不能落在同一分钟。

**番茄钟**默认 25 分钟，范围 1 秒到 99 分 59 秒；再次启动会替换本次时长，不提供暂停。切页后仍继续，重启后取消。少于一分钟仍显示分钟/秒，不显示百分秒。完成提示或取消后恢复普通时钟。

单独说“关闭”“退下”等是退出小智的意图，不应等同于取消闹钟或番茄钟；需要取消任务时请明确说出任务名称。正常退出可等待告别语播放完再回主页。

## 7. 更新与刷写

在“设置 → 系统 → 检查更新”按 BOOT 检查，发现更新后 60 秒内确认下载。下载显示百分比、速度和进度条，校验成功后重启。离线、低电量、配网或已有更新任务时不能启动 OTA。

默认 OTA 主源为 GitHub OTA，备用为 Gitee OTA；自定义 OTA 地址保持原有优先级。新版本仍在构建或镜像同步时，设备可能暂时查不到。不要以文件名相同推断哈希一致。

- **App bin**：只有应用程序，不能写到 `0x0`。必须按当前分区和启动槽位写入。
- **merged bin**：完整刷写镜像，从 `0x0` 写入，可能覆盖配置和资源；提前备份。
- OTA 不会更新分区表。旧 v1.4.x 设备首次迁移到 v1.5.x 及后续布局时，需要按发行说明完整刷写。
- 分区已经正确、希望保留 NVS 时使用明确标注的保留数据刷写方式，不要执行全片擦除。

请勿在更新或写入资源时断电。失败时记录版本和错误日志，再决定重试，避免反复清空 NVS。

## 8. WeatherClock Studio 与自定义资源

右上角 Web Serial 状态与源码加号之间提供四语选择：简体中文、繁体中文（台湾用语）、日本语、英语，默认简体中文。切换即时生效，不清除文件、转换结果、配置输入或连接状态；浏览器只记录语言偏好，存储受限时本次仍可切换。成功缓存网站后，四种语言也可离线使用。

翻译仅限网页工具按钮、说明和应用状态。固件模拟画面、配网模拟器内部、串口原始输出、第三方日志及 Release 原文保持原样；浏览器自己的文件选择和日期控件可能跟随系统语言。切换语言不代表设备固件支持多语言。

[打开网页上位机](https://wickenzh.github.io/ESP32-S3-RLCD-4.2/)。串口写入建议使用桌面 Chrome 或 Edge；浏览器需要串口权限，同一个串口不能同时被其他日志工具占用。

可制作 GIF、图片图库，预览效果，校验和写入固件，查看日志。图片转换和配置生成在浏览器本地进行；固件下载和站点加载仍需要网络。界面模拟不是完整硬件仿真。

“快捷配置”可生成与设备保存接口对应的链接。必须先连接设备配网热点再访问；访问会提交配置，不只是填入表单。链接含明文凭据，应按密码保管，不要公开分享。

资源不存在或校验失败时通常回退内置素材。选择与当前固件分区匹配的工具和文件；不要沿用旧分区地址。清空或替换资源前保留原文件。

## 9. 电池、低电量与恢复出厂

未充电时，电池和温湿度通常白天每分钟、夜间每两分钟采样。电池每次使用多次 ADC 读数中值；疑似上升会短暂按秒确认，稳定后才显示充电，确认失败恢复普通节奏。

没有独立充电状态信号，USB 一直连接不代表电池一直充电。百分比、闪烁和满电时间均为软件估算，不是精密电量计。满电记录要求确认充电、从低于满电阈值开始、持续至少 60 秒并达到阈值；仅因平台期停止动画不会生成记录。

电量过低进入极简模式，暂停非必要联网和音频。恢复电量后回到进入低电量前的页面；该页不可用时回主页。

恢复出厂需要二次确认，会清除 Wi-Fi、天气 Key/Host、手动城市、离线模式、声音与页面设置、单次闹钟；**保留小智绑定、历史记录及自定义资源**。全片擦除与恢复出厂不是同一操作。

## 10. 常见问题与限制

| 现象 | 建议 |
| --- | --- |
| 热点连上却没有网页 | 保持热点连接，手动访问设备地址，暂时关闭移动数据切换 |
| 天气等待数据 | 检查 Key/Host/权限/城市和网络；等待退避后重试，必要时运行网络检测 |
| 页面仍显示旧天气 | 检查最近一次同步是否成功；缓存不是实时测量 |
| 小智准备时间长或服务不可用 | 等待资源释放，检查网络与绑定；保留日志，不连续快速切入切出 |
| 摄氏度/图像异常 | 核对固件与资源版本；截图并记录所在页面 |
| OTA 查不到版本 | 查看源码 Release 与 OTA 镜像是否完成同步 |
| 画面冻结 | 记录时间、页面和最后操作；有日志优先保存，USB连接可能导致复位并丢失现场 |
| 淡影在关机后仍存在 | 可能是屏幕图像滞留，不能只凭残影判定软件未刷新 |

板载温湿度可能受小智、充电和环境热源影响。保持通风，不把设备放在潮湿或过热的位置。本设备的闹钟、天气与测量不应作为安全关键用途的唯一依据。

提交问题前隐去密码、API 凭据、Token、定位和私有地址。许可、第三方声明、贡献与安全政策以仓库原文件为准。
时间和采样昼夜规则按固件固定 UTC+8 处理，当前没有时区设置。夜间慢采样时段为 22:00–05:59。农历、节日沿用固件内置历法资料。
