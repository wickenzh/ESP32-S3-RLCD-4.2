# WeatherClock 使用者詳細說明

[快速入門](User_zh_TW.md) · [简体中文](User_Detailed_zh.md) · [English](User_Detailed.md) · [日本語](User_Detailed_ja.md)

本文件適用於目前的八頁韌體。裝置介面主要使用簡體中文；提供翻譯文件不代表韌體已支援切換介面語言。更新前請先閱讀該版本的發行說明。

## 1. 首次設定

1. 接上電源並等待開機完成。首次使用或恢復原廠設定後，裝置會進入網路設定模式。
2. 用手機或電腦連上螢幕顯示的 WeatherClock 熱點，密碼以裝置畫面為準。
3. 等待設定網頁自動開啟；若沒有出現，請在瀏覽器輸入 `http://192.168.4.1/`。手機若提示無網際網路，請選擇維持連線，並暫時關閉自動切換行動數據。
4. 線上使用須填入主要 Wi-Fi 名稱與密碼、QWeather API Key，以及帳號專屬的 API Host。備用 Wi-Fi 與天氣城市可留白。
5. 儲存後請等待驗證結果。成功後裝置離開設定模式；失敗時依提示修正，不必反覆恢復原廠設定。

API Host 是和風天氣控制台分配給帳號的網域。請填網域本身，不要填 API 路徑、金鑰或已停用的共用網域。驗證失敗時，請一併確認 Host、Key、服務權限與網路連線。請使用自己的天氣帳號，不要使用他人公開的金鑰。

## 2. 按鍵與狀態列

| 操作 | 一般頁面 | 設定頁 |
| --- | --- | --- |
| 短按 BOOT | 下一個已啟用頁面 | 確認或變更選項 |
| 短按 KEY | 開啟設定 | 移動游標 |
| 長按 KEY | 依畫面提示 | 返回上一層，或離開設定 |

設定頁約 30 秒未操作會自動返回；調整頁面順序時也會重新計時。鬧鐘或專注結束音效播放時，任一按鍵會先停止音效，該次按鍵不再執行翻頁。

電池圖示是估算值；閃爍表示推估正在充電，不是 USB 插入指示。Wi-Fi 圖示代表無線電已開啟，不保證能連上網際網路。喇叭與鬧鐘圖示分別表示提醒功能與單次鬧鐘已啟用。

主畫面已有時鐘時，狀態列不重複顯示時間；小智的時鐘區被番茄鐘占用時除外。全天進度列顯示一天的進度。一般更新盡量局部重繪，但翻頁或大範圍內容變更仍可能全畫面更新。

## 3. 八個頁面

| 頁面 | 內容與更新方式 |
| --- | --- |
| 天氣時鐘 | 大時鐘、天氣、警報、GIF 與本機溫溼度；秒級時間，天氣依整點需求同步 |
| 圖片時鐘 | 圖片、分鐘時鐘與每日文字；圖片依設定切換 |
| 天氣看板 | 即時天氣、預報、空氣品質、風力、日出日落與建議；倒數按分鐘更新 |
| 溫溼時鐘 | 時分秒、溫溼度、趨勢、表情與日期農曆 |
| 月曆 | 當月日期、農曆、節日與今日標示；日期變更或重新進入時更新 |
| 溫溼歷史 | 最近 24 小時曲線；背景持續記錄每小時樣本 |
| 小智 AI | 喚醒、語音對話、字幕、表情與語音工具 |
| 整合時鐘 | 秒級時間、當天天氣、日期農曆與本機溫溼度，共用既有資料 |

上述名稱為閱讀用譯名，裝置上的實際選項以簡體中文標示。天氣服務的氣溫與板載感測器測得的溫度來自不同位置，不宜直接視為同一測量。箭頭比較最近四小時有效樣本的移動平均，重新開機後會重新累積。

內建圖片依星期對應，每天午夜切換。自行上傳的圖庫會優先使用，可選 30 分鐘、1、6、12、24 小時，以午夜為切換基準。每日文字另有快取。

天氣建議依當日預報產生，即使目前晴朗，其他時段有雨仍可能提醒帶傘。同步失敗時可能保留舊資料，並不表示已成功取得最新天氣。

## 4. 網路、城市與離線使用

可儲存主要與備用兩組 Wi-Fi，備用可不填。首選多次失敗後會試另一組，成功的組別會成為新首選。兩組皆無法使用時會延後重試；要修改帳密請重新進入網路設定。

城市留白會使用 IP 自動定位，結果可能不準。可透過設定網頁、網頁工具或小智指定城市；遇到同名城市請補上地區並確認結果。「設定 → 網路 → 天氣城市」可再次確認後清除手動城市，改回自動定位，並要求重新同步。

自動 IP 定位會在目前 Wi-Fi 槽位、SSID 與本機 IP 未變更時暫存於記憶體，最長六小時；切換網路槽位、修改網路設定或本機 IP 改變後會重新查詢。若定位仍不準，請改設手動城市。

離線使用時，Wi-Fi 留白並填有效的本地日期與時間，不需要 Key 或 Host；線上設定則可將離線日期時間留白。

離線模式會停止一般連網，也無法啟用天氣時鐘、圖片時鐘、天氣看板、小智 AI 與整合時鐘。溫溼時鐘、月曆與溫溼歷史仍可使用。關閉離線模式時，若設定完整便直接恢復；否則經二次確認進入網路設定。離線不會等同於清除全部快取。

## 5. 設定項目

- 網路：網路設定、同步時間、天氣、每日文字與清除手動城市。
- 聲音：選擇現有音效、音量、整點與全天提醒。
- 顯示：頁面開關、順序、小智節能、鬧鐘與圖片切換。
- 系統：離線模式、網路檢測、恢復原廠設定、裝置資訊及檢查更新。

頁面順序只列出已啟用項目，KEY 選取、BOOT 依提示交換位置。第一項是首頁；至少保留一個非小智頁面，小智不能排第一。溫溼歷史可像其他一般頁面一樣停用與排序，沒有固定五分鐘返回限制。

小智節能預設開啟，閒置五分鐘後返回首頁，番茄鐘執行時暫停此規則。內建圖庫的切換週期固定為 24 小時，只有自訂圖庫能調整。

## 6. 小智、鬧鐘與番茄鐘

首次使用小智可能需要完成帳號綁定，請依畫面或語音操作。它需要網路，待機喚醒也比一般時鐘耗電；長時間使用造成的板子升溫可能影響感測數值。

可以要求「明天早上六點半叫我」、「開始二十五分鐘番茄鐘」、「還剩多久」、「取消番茄鐘」、「把天氣城市改成台北」或「改為自動定位」。支援的語言依小智服務設定而定。請確認螢幕結果，口頭答覆不一定代表工具已成功執行。

單次鬧鐘只能有一個，覆蓋不同時間的既有鬧鐘需要確認，設定頁也能關閉。到點後響鈴最長約一分鐘，每次音效間隔約五秒；按任一鍵停止。鬧鐘與番茄鐘結束時間不可落在同一分鐘。

番茄鐘預設 25 分鐘，可設 1 秒到 99 分 59 秒，再次啟動會替換時長，不提供暫停。翻頁後繼續計時，重新開機會取消；不足一分鐘仍顯示分、秒。取消或完成提示結束後恢復一般時鐘。

只說關閉或退下，是離開小智的意圖，不代表取消鬧鐘或專注計時；要取消時請說明是哪個任務。正常離開可等待道別語播放完畢再返回首頁。

## 7. 韌體更新與燒錄

在系統設定檢查更新，按 BOOT 開始；找到新版本後須在 60 秒內再次確認。下載時顯示百分比、速度與進度條，驗證完成後重新開機。離線、低電量、網路設定中或已有更新時，不能開始 OTA。

預設以 GitHub OTA 為主、Gitee OTA 為備援，並保留自訂伺服器優先順序。發布後可能須等待建置與鏡像同步，才能在裝置上看到版本。

- App bin 只包含應用程式，不能寫到 `0x0`，須配合正確的應用分割區與啟動槽位。
- merged bin 是完整映像，從 `0x0` 燒錄，可能覆蓋設定與素材，請先備份。
- OTA 不會更新分割表。舊 v1.4.x 首次改用新版分割配置時，請依發行說明完整燒錄。
- 已有正確分割表且希望保留設定時，使用明確標示保留 NVS 的方式，不要全片清除。

更新時不要斷電。遇到失敗請先保存版本與錯誤資訊，再判斷是否重試。

## 8. 網頁工具與素材

右上角 Web Serial 狀態與原始碼加號之間可選擇繁體中文（臺灣用語）、簡體中文、日文或英文，預設為簡體中文。切換立即生效，已選檔案、轉換結果、設定輸入與連線狀態都會保留。瀏覽器僅記錄語言偏好；儲存受限時仍可在本次使用中切換。網站完成快取後，四種語言皆可離線使用。

翻譯僅涵蓋網頁工具的按鈕、說明與狀態。韌體模擬畫面、連網設定模擬器內部、原始序列埠輸出、第三方日誌及 Release 原文維持原樣；瀏覽器的檔案選擇及日期控制項可能依系統語言顯示。切換網頁語言不代表韌體支援多語言。

[開啟 WeatherClock Studio](https://wickenzh.github.io/ESP32-S3-RLCD-4.2/)。串列埠功能建議用電腦版 Chrome 或 Edge，並關閉其他占用同一連接埠的程式。

可轉換 GIF、製作圖庫、預覽介面、驗證與燒錄韌體、查看記錄。素材轉換與設定產生在瀏覽器本機進行，但載入網站與下載韌體仍需要網路。模擬預覽不能取代真實硬體測試。網頁支援窄螢幕瀏覽，模擬器會自動改為上下排列；素材寫入、韌體燒錄與序列埠功能仍需支援 Web Serial 的電腦版 Chrome 或 Edge。

韌體頁的「線上完整安裝」預設使用最新正式版 merged 韌體。首次安裝或分割區遷移時，請先連線並確認晶片為 ESP32-S3、Flash 容量可辨識，再確認覆蓋韌體、分割表與素材；空白或無效分割表不會阻止完整安裝。若要保留裝置設定或自訂素材，請取消完整安裝，於「進階韌體燒錄」讀取有效分割表後改用 App 更新。驗證失敗不會寫入，完成後頁面不會自動跳轉；手機僅能瀏覽，序列埠操作仍需電腦版 Chrome/Edge。

快捷設定會產生提交到裝置的連結。先連上裝置熱點再開啟；這會直接儲存設定，不只是帶入表單。連結含明文帳密，請妥善保管，不要公開。

素材不存在或驗證失敗時通常會使用內建素材。請使用符合目前分割配置的工具，不要套用舊版位址。

## 9. 電池與恢復原廠設定

平時電池與溫溼度在白天約每分鐘、夜間約每兩分鐘取樣。電池使用多筆 ADC 中值；疑似充電時短暫按秒確認，持續穩定才顯示充電，否則回到原取樣週期。

本邏輯沒有獨立充電狀態訊號，USB 插著不表示電池持續充電。電量、閃爍和上次充滿時間都是推估。滿電紀錄須從低於門檻開始、確認充電並持續至少 60 秒、實際達到門檻；單純因電壓平台而停止閃爍不算充滿。

低電量時進入精簡畫面並暫停非必要網路和音效。電量恢復後返回先前頁面，不可用時改回首頁。

恢復原廠設定須二次確認，清除 Wi-Fi、天氣 Key/Host、手動城市、離線模式、聲音、頁面設定及單次鬧鐘；保留小智綁定、歷史資料和自訂素材。這與整片 Flash 清除不同。

## 10. 排除問題

- 沒有設定網頁：確認仍連裝置熱點，手動開啟本機位址。
- 天氣未更新：檢查金鑰、Host、權限與網路，等待延後重試或使用網路檢測。
- 小智無法使用：確認網路與綁定，等待資源釋放，不要連續快速切頁。
- 畫面卡住：記下時間、頁面與操作，優先保存記錄；USB 連線可能觸發重設，導致現場消失。
- 關機仍有淡影：可能是面板影像殘留，不宜單憑這點判斷程式沒更新。

充電、小智與附近熱源都可能影響板載溫溼度。請保持通風、避免潮溼高溫，也不要以本裝置作為安全關鍵提醒或精密量測的唯一依據。公開問題記錄前請移除帳密、定位及私人位址；授權與第三方條款以儲存庫原文件為準。
時鐘與日夜取樣採固定 UTC+8，沒有時區切換設定；夜間慢取樣為22:00–05:59。農曆與節日沿用韌體內建資料，不代表已完整支援台灣的國定假日。

## 可選天氣來源

開啟後，和風 Key/Host 欄位仍會顯示，但無法輸入；關閉開關即可重新編輯。網路檢測會使用目前的天氣來源；關於本機顯示此來源最近一次成功同步的時間，切換後須等待首次同步成功。

裝置設定網頁與 WeatherClock Studio 快捷設定新增「使用 Open-Meteo」開關，預設關閉。關閉時使用和風天氣及原有 Key/Host；開啟後不需填這兩項，已儲存的和風憑據仍保留，不會自行切回。改回和風時須有有效憑據。

Open-Meteo 為氣象模型資料，空氣品質標示 US AQI，不是中國 AQI；此整合不提供天氣警報，畫面會明確提示。公共介面僅供非商業使用，仍須確認網路可連線。快捷連結需要支援雙天氣來源的新韌體，舊版可能忽略選項。離線仍只需有效日期時間。

資料：[Open-Meteo](https://open-meteo.com/)、[CAMS](https://atmosphere.copernicus.eu/)；城市：[GeoNames](https://www.geonames.org/)。
