# WeatherClock 詳細ユーザーガイド

[クイックスタート](User_ja.md) · [简体中文](User_Detailed_zh.md) · [繁體中文](User_Detailed_zh_TW.md) · [English](User_Detailed.md)

現在の8画面構成のファームウェアを対象とします。本体の表示は主に簡体字中国語です。日本語マニュアルの提供は、本体の言語切り替え機能を意味しません。更新前に各バージョンのリリースノートも確認してください。

## 1. 初期設定

1. 電源を入れ、起動が完了するまで待ちます。初回起動や工場出荷時設定へのリセット後は、接続設定モードになります。
2. スマートフォンまたはPCから、本体に表示された WeatherClock のアクセスポイントに接続します。パスワードは本体表示を確認してください。
3. 設定画面が自動で開かない場合は、ブラウザーで `http://192.168.4.1/` を開きます。「インターネット接続なし」と表示されても接続を維持し、必要に応じてモバイル通信への自動切り替えを無効にします。
4. オンラインで使う場合は、メインの Wi-Fi 名とパスワード、QWeather API Key、アカウント専用の API Host を入力します。予備の Wi-Fi と天気の都市は省略できます。
5. 保存して検証結果を待ちます。成功すると通常画面に移ります。失敗した場合は表示された項目を修正してください。

API Host は QWeather の管理画面で割り当てられるドメインです。API のパス、キー、廃止された共通ドメインを入力しないでください。検証できないときは、Host、Key、サービスの利用権限、ネットワークを確認します。他人が公開したキーではなく、自分のアカウントを使用してください。

## 2. ボタンとステータス表示

| 操作 | 通常画面 | 設定画面 |
| --- | --- | --- |
| BOOTを短く押す | 次の有効な画面へ | 決定・設定変更 |
| KEYを短く押す | 設定を開く | 選択項目を移動 |
| KEYを長押し | 画面の案内に従う | 1つ前の階層へ戻る、設定を終了 |

設定画面は約30秒操作しないと終了します。画面の並べ替え操作もタイマーを更新します。アラームや集中タイマーの終了音が鳴っている間は、どちらのボタンでも音を止められます。その押下では画面切り替えなどは行いません。

電池残量と充電中の点滅は推定表示です。USB接続そのものを表す表示ではありません。Wi-Fiアイコンは無線機能が動作していることを示し、インターネット接続の成功を保証しません。スピーカーとアラームのアイコンは、それぞれ通知機能と単発アラームの有効状態です。

メイン部分に時計がある画面では、上部に時刻を重複表示しません。ただしAIの時計部分を集中タイマーに使っている間は上部にも表示します。通常は変化した部分だけを描画しますが、画面切り替えや大きな変更では全体を描画する場合があります。

## 3. 8つの画面

| 画面 | 内容と更新 |
| --- | --- |
| 天気時計 | 大きな時計、天気、警報、GIF、室内の温湿度。時刻は秒単位 |
| 画像時計 | 画像、分単位の時計、今日のひとこと |
| 天気ダッシュボード | 現在の天気、予報、大気質、風、日の出・日の入り、アドバイス |
| 温湿度時計 | 時・分・秒、温湿度、傾向、表情、日付と旧暦 |
| カレンダー | 月表示、旧暦、祝日表示、今日の強調 |
| 温湿度履歴 | 過去24時間のグラフ。画面を閉じても毎時の記録を継続 |
| Xiaozhi AI | ウェイクワード、音声対話、字幕、表情、音声ツール |
| 統合時計 | 秒単位の時計、当日の天気、日付・旧暦、本体センサーの温湿度 |

画面名は説明用の訳語です。本体のメニューは中国語表記を参照してください。天気サービスの気温と本体センサーの値は測定場所が異なります。傾向の矢印は過去4時間の有効なサンプルによる移動平均の変化を表し、再起動すると蓄積し直します。

内蔵画像は曜日に対応し、午前0時に切り替わります。アップロードした画像は内蔵画像より優先され、30分、1、6、12、24時間周期を選べます。切り替えの基準は午前0時です。

天気は共有キャッシュを使い、必要な画面で毎正時を基準に同期します。日の出・日の入りまでの表示は分単位です。アドバイスは当日の予報に基づくため、現在晴れていても雨への備えを勧めることがあります。通信失敗後は以前の値が残る場合があります。

## 4. Wi-Fi、都市、オフライン

メインと予備の2組を保存できます。優先する接続先で失敗が続くともう一方を試し、成功した接続先が新しい優先先になります。両方に接続できない場合は間隔を空けて再試行します。

都市を空欄にするとIPアドレスに基づく自動位置判定を使います。必ずしも正確ではありません。設定ページ、ブラウザーツール、AIの天気都市ツールで実在する都市を指定し、同名の都市がある場合は地域名も添えて結果を確認してください。

ネットワーク設定の天気都市項目では、確認操作後に手動設定を消去して自動に戻せます。その後、天気の更新を要求します。音声処理などが動作中の場合は更新が遅れることがあります。

オフラインで使う場合はWi-Fiを空欄にし、正しい現地の日付と時刻を入力します。KeyとHostは不要です。オンライン設定の場合、オフライン用の日付・時刻は空欄のままで構いません。

オフライン中は天気時計、画像時計、天気ダッシュボード、AI、統合時計を有効にできません。温湿度時計、カレンダー、履歴は使用できます。オンライン設定が不足した状態で解除しようとすると、確認後に接続設定へ移ります。オフラインへの切り替えは全データの消去ではありません。

## 5. 設定メニュー

- ネットワーク：接続設定、時刻・天気・ひとことの同期、手動都市の解除。
- サウンド：音源、音量、毎時・終日の通知。
- 表示：画面の有効化、順序、AI省電力、アラーム、画像切り替え周期。
- システム：オフライン、ネットワーク診断、リセット、本体情報、更新確認。

並べ替えには有効な画面だけが表示されます。KEYで選択し、BOOTで案内に従って入れ替えます。先頭がホーム画面です。AI以外の画面を最低1つ残す必要があり、AIは先頭にできません。履歴画面には固定の5分自動復帰制限はありません。

AI省電力は初期状態で有効です。AI画面で5分間操作がないとホームへ戻りますが、集中タイマーの動作中は自動復帰しません。内蔵画像の周期は24時間固定です。

## 6. AI、アラーム、集中タイマー

初回はアカウントの有効化が必要な場合があります。本体の案内に従ってください。AIはネットワークが必要で、待ち受け中も時計画面より消費電力が大きくなります。基板の発熱が温湿度測定に影響することもあります。

「明日の朝6時半に起こして」「25分の集中タイマーを始めて」「残り時間は？」「集中タイマーを取り消して」「天気の都市を東京にして」といった意図を伝えます。利用できる音声言語はXiaozhiサービスの設定によります。返答だけでなく、本体の設定結果も確認してください。

保存できるアラームは単発1件です。別の時刻で上書きする際には確認が必要で、設定画面から無効にもできます。約5秒間隔で音を繰り返し、最長約1分で終了します。どちらかのボタンで停止でき、鳴動後は無効になります。アラームと集中タイマーの終了通知を同じ分に設定することはできません。

集中タイマーの初期値は25分、範囲は1秒から99分59秒です。再設定すると現在の時間を置き換えます。一時停止はありません。画面を変えても継続しますが、再起動すると取り消されます。残り1分未満でも分・秒表示を使い、百分の一秒表示は行いません。取り消しや終了表示の後は通常の時計に戻ります。

AIを「閉じて」「終了して」と依頼することと、アラームや集中タイマーを取り消すことは別です。取り消したい場合は対象を明確にしてください。正常な終了では、別れのメッセージの再生後にホームへ戻る場合があります。

## 7. 更新と書き込み

システム設定で更新確認を選びBOOTを押します。新しい版がある場合、60秒以内に再度確認するとダウンロードします。割合、速度、進捗バーが表示され、検証後に再起動します。オフライン、低電池、接続設定中、別の更新中は実行できません。

標準の主配信元はGitHub OTA、予備はGitee OTAです。独自サーバーの優先設定も利用できます。公開直後はビルドやミラーの同期が終わるまで見つからない場合があります。

- App binはアプリのみです。`0x0`には書かず、現在のパーティションと起動スロットに合わせます。
- merged binは完全なイメージで、`0x0`から書き込みます。設定や素材を上書きする可能性があるため、先にバックアップしてください。
- OTAではパーティションテーブルを更新できません。旧v1.4.xから新しい構成へ移る場合は、リリースノートに従ってシリアル経由で全体を書き込みます。
- データを残したい場合は、NVS保持と明記された手順を使い、フラッシュ全体を消去しないでください。

書き込み中は電源を切らないでください。失敗時はバージョンとログを保存し、原因を確認してから再試行します。

## 8. ブラウザーツールと素材

右上のWeb Serial状態とソースへのショートカットの間で、日本語・英語・簡体字中国語・繁体字中国語（台湾）を選べます。初期設定は簡体字中国語です。切替は即時反映され、選択ファイル、変換済み素材、設定入力、接続状態は保持されます。保存されるのは言語設定のみです。保存が制限されても、そのセッション中は切替できます。サイトのキャッシュ完了後は4言語ともオフラインで使えます。

翻訳対象はWebツールのボタン、説明、アプリの状態表示です。ファームウェアのシミュレーター画面、Wi-Fi設定デモ内部、生のシリアル出力、外部ツールのログ、Release原文は変更しません。ブラウザー標準のファイル選択や日付入力はシステム言語に従う場合があります。Webの言語切替でファームウェア自体が多言語対応になるわけではありません。

[WeatherClock Studioを開く](https://wickenzh.github.io/ESP32-S3-RLCD-4.2/)。シリアル操作はPC版ChromeまたはEdgeを推奨します。アクセス許可を与え、同じポートを使う他のソフトを閉じてください。

GIF・画像の変換、画面プレビュー、ファームウェアの検証と書き込み、ログ表示ができます。素材の変換や設定生成はブラウザー内で処理しますが、サイトやファームウェアのダウンロードには通信が必要です。プレビューは実機のすべての動作を再現するものではありません。Web UIは狭い画面で閲覧でき、シミュレーターは上下配置になります。素材書き込み、ファームウェア書き込み、シリアル操作にはWeb Serial対応のPC版ChromeまたはEdgeが必要です。

ファームウェア画面の既定は最新の正式版mergedによる「オンライン完全インストール」です。初回導入やパーティション移行では、デバイスを接続してESP32-S3とFlash容量を確認してから、ファームウェア・パーティション・素材の上書きを確認してください。空の、または無効なパーティション表でも完全インストールは続行できます。設定や自作素材を残す場合はキャンセルし、有効なパーティション表を読み取ったうえで「高度なファームウェア書き込み」のApp更新を使います。検証に失敗した場合は書き込みません。完了後の自動遷移もありません。スマートフォンは閲覧のみで、シリアル書き込みには使えません。

簡易設定リンクは本体の保存処理を呼び出します。先に本体のアクセスポイントへ接続してください。開くと設定を送信し、単なる入力補助ではありません。認証情報を平文で含むため、パスワードと同様に保管し、公開しないでください。

素材がない場合や検証できない場合は、通常は内蔵素材に戻ります。現在のパーティションに対応するツールを使い、元の素材ファイルを保存しておいてください。

## 9. 電池とリセット

通常、電池と温湿度は昼間に約1分、夜間に約2分間隔で測定します。電池電圧は複数のADC値の中央値を使います。充電らしい上昇を検出すると一時的に秒単位で確認し、安定してから充電表示に変えます。

独立した充電状態信号は使っていません。USB接続中でも電池への充電が続いているとは限りません。残量・点滅・前回の満充電時刻は推定です。満充電記録には、しきい値未満から始まる確認済み充電、60秒以上の継続、しきい値到達が必要です。電圧が横ばいになって点滅を止めただけでは記録しません。

低電池では簡易画面に移り、不要な通信や音声を止めます。回復すると直前の画面へ戻り、その画面が無効ならホームへ戻ります。

工場出荷時設定へのリセットは確認後に実行され、Wi-Fi、天気Key/Host、手動都市、オフライン、音・画面設定、単発アラームを消去します。AIの紐付け、履歴、自作素材は保持します。フラッシュ全消去とは異なります。

## 10. トラブル対処

- 設定画面が開かない：本体のアクセスポイントへの接続を維持し、ローカルアドレスを直接開きます。
- 天気が更新されない：Key、Host、権限、都市、通信状態を確認し、再試行を待ちます。
- AIが使えない：ネットワークと有効化を確認し、準備が終わるまで待ちます。
- 画面が止まった：時刻、画面、直前の操作とログを保存してください。USB接続でリセットされ、現象が失われることがあります。
- 電源を切っても薄い像が残る：パネルの残像の可能性があり、描画処理の不具合とは限りません。

充電やAI、周囲の熱源は温湿度値に影響します。湿気や高温を避け、通気を確保してください。本機の通知・計測を安全に関わる用途の唯一の手段にはしないでください。ログを共有する際は、認証情報、位置、私用アドレスを除いてください。ライセンスなどの条件はリポジトリの原文書を参照してください。
時刻と昼夜の測定周期はUTC+8固定です。日本標準時（UTC+9）より1時間遅く、時刻同期後もUTC+8になります。夜間の低頻度測定は22:00–05:59です。旧暦・祝日表示は内蔵の中国語カレンダー情報に基づき、日本の祝日への対応を保証するものではありません。

## 天気サービスの選択

Open-Meteoを選択してもQWeatherのKey/Host欄は表示されたままですが、入力できなくなります。スイッチをオフにすると再び編集できます。ネットワーク診断は選択中のサービスを使い、本体情報にはそのサービスとの最終同期成功時刻を表示します。切り替え後は最初の同期完了までお待ちください。

本体の接続設定とWeatherClock Studioの簡易設定に、Open-Meteoを使うスイッチを追加しました。初期状態はオフで、従来どおりQWeatherのKey/Hostを使います。オンならそれらは不要です。保存済みのQWeather認証情報は消さず、自動で別サービスへ切り替えることもありません。QWeatherへ戻す場合は有効な認証情報が必要です。

Open-Meteoの天気はモデルに基づき、大気質はUS AQIとして表示します。中国のAQIとは異なります。この連携は気象警報に対応せず、画面にも非対応と表示します。公開APIは非商用向けで、通信品質の保証はありません。簡易設定リンクは対応ファームウェアが必要です。旧版では選択を無視する場合があります。オフラインでは引き続き日時だけを設定します。

データ提供：[Open-Meteo](https://open-meteo.com/)、[CAMS](https://atmosphere.copernicus.eu/)。都市検索：[GeoNames](https://www.geonames.org/)。
